# StockPar

Sistema de gestión de repuestos importados con precios en dólares, desarrollado para el Trabajo Parcial 1 de la materia Análisis y Metodología de Sistemas.

## Descripción

StockPar está pensado para una distribuidora que compra repuestos en dólares estadounidenses y los vende en pesos argentinos.

El sistema busca reemplazar el uso de planillas desactualizadas, automatizar el cálculo de precios, controlar el stock y conservar un historial de las cotizaciones realizadas.

## Funcionalidades principales

* Gestión de usuarios con roles de Administrador y Vendedor.
* Registro y actualización de proveedores.
* Administración del catálogo de repuestos.
* Registro histórico de la cotización del dólar.
* Conversión de precios de USD a ARS.
* Aplicación de márgenes de ganancia.
* Consulta del stock disponible.
* Alertas de stock mínimo.
* Generación de cotizaciones para clientes.
* Registro del vendedor y del valor del dólar utilizado.

## Usuarios

### Administrador

Puede administrar repuestos, proveedores, cotizaciones del dólar y niveles de stock.

### Vendedor

Puede consultar productos, precios y disponibilidad, además de generar cotizaciones para los clientes.
